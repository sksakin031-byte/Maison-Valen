Privacy note

This page describes the behavior of the GitHub Pages preview, not a complete privacy policy for a production WordPress website.

What this preview does

This site is served as static files by GitHub Pages. It does not include WordPress, a database, analytics, or a form-submission backend. The contact links open an external email application or WhatsApp; this preview does not store messages.

Third-party services

When you follow an external email or WhatsApp link, that service handles any information you choose to provide under its own policies. GitHub Pages may process ordinary technical request data as part of serving the site.

Production use

The ZIP includes a WordPress theme with dynamic features. Before using that theme on a live WordPress site, the site owner should provide and review a complete privacy policy that reflects the actual hosting, analytics, forms, and data practices.
